# Колесо АЮ READY КВИЗ

Рандомайзер для розыгрышей. Данные общие: вбил участников на телефоне — сразу появились на компьютере и на проекторе, и наоборот. Крутить можно с любого устройства — колесо закрутится на всех открытых экранах с одним и тем же победителем.

## Загрузка на Render (как приложение подсчёта баллов)

1. В репозитории `randomaizer` на GitHub удали старые файлы и загрузи новые: `server.js`, `package.json`, `index.html`, `logo.png`, `README.md` (Add file → Upload files → Commit changes).
2. На Render удали старый **Static Site** randomaizer (Settings → внизу Delete).
3. **New → Web Service** → репозиторий `randomaizer`.
   - Language: **Node**
   - Build Command: `npm install`
   - Start Command: `node server.js`
   - Instance Type: **Free**
4. Create Web Service. Через пару минут будет адрес вида `https://randomaizer.onrender.com`.

## Особенности бесплатного тарифа

- Через 15 минут без посетителей сервис засыпает, первое открытие после этого — до минуты. Открой ссылку минут за 5 до розыгрыша.
- При засыпании данные на сервере могут стереться. Каждое устройство, где ты вводил участников, хранит копию и само вернёт её на сервер при следующем открытии — у всех снова всё появится.
- Индикатор вверху панели: зелёный «Синхронизировано» — всё сохранено; красный — нет связи, изменения отправятся сами, когда связь вернётся.

## Второй экран

Подключи проектор как расширенный экран (Win + P → «Расширить»), открой сайт в Chrome или Edge и нажми «Режим показа на 2-м экране». На втором экране — двойной клик в любом месте для полного экрана.
