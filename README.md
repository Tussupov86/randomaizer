# Колесо АЮ READY КВИЗ

Рандомайзер для розыгрышей с трансляцией на второй экран.

## Загрузка на Render (бесплатно, Static Site)

1. Создай на GitHub новый репозиторий (например `ayu-wheel`) и загрузи в него `index.html` и `logo.png`.
2. На render.com: **New → Static Site** → выбери этот репозиторий.
3. Build Command — оставь пустым. Publish Directory — `.` (точка).
4. Create Static Site. Через минуту сайт будет по адресу вида `https://ayu-wheel.onrender.com`.

Static Site на Render не «засыпает», в отличие от бесплатного Web Service, — открывается сразу.

## Второй экран

1. Подключи проектор/ТВ как **расширенный** экран (Windows: Win + P → «Расширить»).
2. Открой сайт в **Chrome или Edge** и нажми «Режим показа на 2-м экране».
3. В первый раз браузер спросит разрешение на **управление окнами** и, возможно, на **всплывающие окна** — разреши оба.
4. Колесо откроется на втором экране. Если там осталась рамка окна — дважды кликни мышкой в любом месте второго экрана (или клавиша F).

Звук играет из вкладки-пульта. Список участников и история сохраняются в браузере.
